# TUSI Client PC

TUSI Client is a Windows Minecraft launcher/client project.

Build is performed using GitHub Actions Windows runner.

Features foundation:
- TUSI white/blue UI
- TUSI Boost
- FPS optimization profile
- RAM/JVM optimization settings
- Fabric version UI
- Modrinth UI
- Cosmetics UI
- Microsoft login UI
- Windows EXE / portable build

The launcher does not bypass Microsoft/Minecraft authentication.
